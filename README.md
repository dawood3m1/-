# 🚑 اسعفني — As'afni

**زر واحدة… تنقذ حياة**

تطبيق إسعافي يُسرّع وقت وصول المسعف ويوفر له البروفايل الصحي الكامل للحالة قبل الوصول.

---

## 🎯 الفكرة

عند وقوع حالة طارئة، يضغط المستخدم زر الإسعاف الأحمر فيُرسل **موقعه بدقة عالية فوراً** للمسعف مع **البروفايل الصحي الكامل** (الأدوية، الحساسية، فصيلة الدم، الأمراض المزمنة، العمليات السابقة). هذا يختصر الوقت في كل مرحلة: من البلاغ حتى وصول المسعف.

---

## ✨ المميزات الرئيسية

### للمستخدم (المبلغ)
| الميزة | الوصف |
|--------|-------|
| 📍 **تحديد الموقع عالي الدقة** | GPS عالي الدقة + متابعة حية (`watchPosition`) |
| 🔧 **تعديل الموقع يدوياً** | سحب الدبوس على مدخل المبنى بالضبط |
| 👤 **اختيار هوية الحالة** | أنا / عائلة / صديق / شخص غير معروف |
| 🔄 **تبديل البروفايل الفوري** | يتغير ملف المسعف حسب الاختيار |
| ⚡ **اختصارات الحالة** | إغماء، دوار، نزيف، ألم صدر، صعوبة تنفس... |
| 🏠 **أماكن محفوظة** | حفظ المنازل والأماكن مع الرقم وصورة المدخل |
| 📁 **القائمة السريعة** | ☰ قائمة بإضافة أماكن وعرض المحفوظات |
| 🌓 **وضع ليلي/نهاري** | تصميم مريح للعين مع تبديل فوري |

### للمسعف (قريباً)
| الميزة | الوصف |
|--------|-------|
| 📊 **داشبورد شامل** | البروفايل الصحي الكامل للحالة |
| 🗺️ **موقع حي مباشر** | متابعة الموقع أثناء التحرك |
| 🤖 **مساعد ذكاء اصطناعي** | تلخيص البيانات واقتراحات الأولوية |
| 📞 **اتصال مباشر** | زر اتصال فوري بالمبلغ |

### للنظام (قريباً)
| الميزة | الوصف |
|--------|-------|
| 🪪 **بطاقة NFC** | بطاقة رقمية تحمل البيانات الأساسية |
| 🔗 **ربط نفاذ** | تحقق من الهوية وجلب العائلة تلقائياً |
| 👨‍👩‍👧 **تنبيه الأقارب** | إشعار فوري عند بلاغ عن أحد الأفراد |

## 🛠️ التقنيات

- **الواجهة:** HTML5 / CSS3 / JavaScript (PWA)
- **الخرائط:** Leaflet + OpenStreetMap (CARTO Dark/Light Tiles)
- **الموقع:** Geolocation API (`enableHighAccuracy` + `watchPosition`)
- **التخزين:** localStorage (للأماكن المحفوظة والتفضيلات)
- **الخط:** Tajawal (Google Fonts)

## 🚀 التشغيل

1. افتح المجلد في terminal
2. شغّل سيرفر محلي (الـ GPS يحتاج HTTPS في الإنتاج):
   ```bash
   python -m http.server 8000
   ```
3. افتح المتصفح على `http://localhost:8000`

> ⚠️ **ملاحظة:** خاصية الموقع (GPS) تحتاج HTTPS في الإنتاج أو استخدام `localhost`. على الجهاز الفعلي، افتح الملف مباشرة بالمتصفح واسمح بالوصول للموقع.
