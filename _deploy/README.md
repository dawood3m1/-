# 🚑 اسعفني — As'afni

**زر واحدة… تنقذ حياة**

تطبيق إسعافي يُسرّع وقت وصول المسعف ويوفر له البروفايل الصحي الكامل للحالة قبل الوصول.

---

## 🎯 الفكرة

عند وقوع حالة طارئة، يضغط المستخدم زر الإسعاف الأحمر فيُرسل **موقعه بدقة عالية فوراً** للمسعف مع **البروفايل الصحي الكامل** (الأدوية، الحساسية، فصيلة الدم، الأمراض المزمنة، العمليات السابقة). هذا يختصر الوقت في كل مرحلة: من البلاغ حتى وصول المسعف.

## 🛠️ التقنيات

- **الواجهة:** HTML5 / CSS3 / JavaScript (PWA)
- **الخرائط:** Leaflet + OpenStreetMap (CARTO Dark/Light Tiles)
- **الموقع:** Geolocation API (`enableHighAccuracy` + `watchPosition`)
- **الربط الحي:** BroadcastChannel + localStorage (تنبيه Storage) — بلاغ من صفحة المستخدم يظهر في لوحة المسعف لحظياً
- **التدوين الصوتي:** Web Speech API (إملاء حقيقي + استخراج العلامات الحيوية)
- **التخزين:** localStorage (أماكن محفوظة + بلاغات حية)
- **الخط:** Tajawal (Google Fonts)

---

## 🔗 الربط الحي بين الصفحتين

- **`realtime.js`** قناة مشتركة بين `index.html` و `paramedic.html`.
- **إرسال فوري من كل ضغطة زر:** بمجرد الضغط على زر الطوارئ الأحمر يصل الموقع للوحة المسعف، وكل اختيار لاحق (شخص، حالة، وصف) يُرسل تحديثاً فورياً لنفس البلاغ — دون انتظار تأكيد نهائي.
- لوحة المسعف تفتح البلاغ تلقائياً، وعند تغيير الحالة (قبول / تحرّك / وصول) ترى صفحة المستخدم التحديث لحظياً.
- زر «إنهاء وإزالة» في لوحة المسعف يحذف البلاغ المكتمل ليتسنّى إعادة التجربة دون تراكم.
- يعمل بين تبويبين متجاورين في نفس المتصفح والجهاز.
- مستقبلاً عند تفعيل بطاقة NFC سيُحوَّل هذا الربط إلى خادم (WebSocket / Firebase) للعمل عبر أجهزة متعددة.

## 🧩 إضافة السيناريوهات

كل بيانات السيناريوهات في `scenarios.js`. الملف يأتي محمّلاً بسيناريو مثال جاهز (أسرة خالد الجدعان) ويمكن تعديله أو استبداله:

```js
window.SELF_DATA = { name, age, blood, allergy, drugs, ops, chronic };
window.SCENARIO_FAMILY = [ { relation, name, age, blood, drugs, allergy, ops, chronic } ];
window.SCENARIO_FRIENDS = [ { name, age, blood, drugs, allergy, ops, chronic } ];
window.SCENARIO_NEARBY  = [ { name, age, blood, drugs, allergy, ops, chronic } ];
```

- `SELF_DATA` → بروفايل «أنت» (يظهر في سجلي الطبي وبطاقتي الإسعافية وأي بلاغ باسمك).
- `SCENARIO_FAMILY` → أفراد العائلة الذين يظهرون عند «أحد أفراد عائلتي».
- `SCENARIO_FRIENDS` → أصدقاؤك — يُحدَّثون أيضاً من التطبيق عبر «إضافة صديق» (تُحفظ الإضافات في `localStorage`).
- `SCENARIO_NEARBY` → «شخص لا أعرفه» يلتقطه البلاغ عبر تقريب الهاتف (طريقة NFC) — يُعرض للمستخدم فصيلة الدم فقط، والسجل الكامل يصل للمسعف.

## 🚀 التشغيل

**للتجربة المباشرة (نفس الجهاز):**
1. افتح `index.html` في تبويب — صفحة المستخدم.
2. افتح `paramedic.html` في تبويب آخر في **نفس المتصفح** — لوحة المسعف.
3. من صفحة المستخدم: اختر الشخص ← حدد الحالة ← «إرسال البلاغ النهائي».
4. شاهد البلاغ يصل ويُفتح تلقائياً في لوحة المسعف لحظياً.

> ℹ️ الربط يعمل عبر `realtime.js` (BroadcastChannel + localStorage) فلا يحتاج تحميل ملفات إضافية أو إنترنت سوى لخرائط Leaflet.

**لأفضل تجربة GPS والوضع الليلي:**
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000/index.html` و `http://localhost:8000/paramedic.html`.

> ⚠️ **ملاحظة:** خاصية الموقع (GPS) تحتاج HTTPS في الإنتاج. على الجهاز الفعلي، افتح الملف مباشرة بالمتصفح واسمح بالوصول للموقع (Chrome/Edge هما الأنسب للربط الحي والتدوين الصوتي).
